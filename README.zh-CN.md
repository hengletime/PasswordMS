# PasswordMS

## ✨ 特性

**安全这块**

- **零知识加密**：整卷加密（Argon2id 密钥派生 + XChaCha20-Poly1305 认证加密），主密码不上传、不可找回
- **自动锁定**：窗口闲置 1 / 5 / 15 分钟自动锁定（可调）；Android 切后台超时回前台立即锁定
- **剪贴板自动清空**：复制密码 / 用户名 / 动态口令后按设定秒数（5–120，默认 30）清空，界面显示倒计时。**动态口令例外**：它按口令自己的剩余寿命清空——口令只剩 8 秒，剪贴板就只留 8 秒，绝不留一个已经作废的码给你。倒计时提示只出现在**你复制的那个条目**上，切到别的条目不会跟着跑
- **快速解锁**：Windows Hello（PIN / 指纹 / 人脸）或 Android 指纹代替每次输主密码；密钥只在本机、**不进备份与同步**
- **网址校验**：打开网址前只放行 `http` / `https`，`javascript:`、`file:` 等一律拦下

**日常用起来**

- **两类条目**：登录（网址 / 用户名 / 密码 / TOTP / 自定义字段 / 备注）、安全笔记（正文上限 256 KiB）
- **两步验证（TOTP）**：登录条目存 2FA 密钥，详情页实时显示动态口令；取密钥有四种方式 —— 扫码、从图片、粘贴截图、框选截图（后两种为桌面端），详见下文「两步验证」
- **一键复制**：用户名、密码、动态口令都是一个按钮，粘贴到登录框即可
- **密码生成器**：8–64 位（默认 16），大小写 / 数字 / 符号四类可选，符号可逐个点选，可排除易混字符；生成后可直接填入条目
- **分组与整理**：分组 / 未分组筛选、收藏、钉住、拖拽排序；桌面右键、手机长按可重命名与移动分组
- **搜索**：库内即时筛选（匹配标题 / 用户名 / 网址，不区分大小写），无匹配时明确告诉你「是搜不到，不是库空了」
- **密码体检**：健康分 + 弱口令 / 重复密码 / 超期未改三类问题，阈值（默认 ≤8 位、180 天）可在设置里调
- **回收站**：软删除 → 还原 → 彻底删除，保留 30 天，附件随条目级联清理
- **附件**：单条目最多 16 个、单个 ≤ 20 MB，随保险库一起加密；导出前会二次确认（导出即明文）
- **桌面便捷**：全局热键唤出并聚焦搜索、独立快速搜索小窗（键盘选条目、直接复制）、关窗最小化到托盘、开机自启（可选）

**数据进出与多设备**

- **局域网同步**：扫码配对 + 端到端加密，数据不经任何云端服务器；**手动触发**（原因见下文「同步怎么用」）
- **冲突仲裁**：两端改了同一条时逐条选「保留本机 / 采用远端 / 两者都留」，不会静默覆盖
- **从 Bitwarden 迁移**：导入未加密的 JSON / CSV 导出（10 列自动识别），同名分组合并、重复条目跳过，可下载 CSV 模板；GBK / UTF-16 编码自动转换
- **备份与恢复**：导出整库加密副本（`.vault`），锁屏页「从备份恢复」一键导回；设置页常驻显示上次成功导出的时间与体积
- **检查更新**：默认关闭；开启后每天最多向 GitHub 查一次最新版本，不含任何用户数据
- **压缩保险库**：回收已删附件占用的空间，先如实告诉你「可回收多少」

**平台与体积**

- **双平台**：Windows 10/11（安装版 / 免安装绿色版）+ Android 7.0+（arm64）
- **四语言三主题**：简体中文 / 繁體中文 / English / ไทย（跟随系统语言），浅色 / 深色 / 跟随系统
- **极小体积**：桌面安装包约 2.0 MB，APK 约 7.4 MB

## 🚀 快速开始

1. 下载并安装（或解压绿色版）
2. 首次启动创建保险库，设置**主密码** —— 请务必牢记：**忘记主密码没有任何找回手段**
3. 添加登录 / 笔记条目；需要两步验证的加个 TOTP 密钥，需要的话拖入附件
4. 可选：设置里配一个**全局热键**，之后在任何程序里按一下就能搜条目、复制密码
5. 多设备同步：`设备 → 与新设备配对`，用另一台设备扫码即可（两台设备需在同一局域网）。同步是**手动触发**的，任一端点「立即同步」都能发起——具体见「同步怎么用」

## 🔑 两步验证（TOTP）

登录条目可以带一个两步验证（TOTP）密钥。详情页会一直显示当前的 6 位动态口令和本周期的剩余秒数，到点自动换成下一个；口令末尾那个复制按钮可以直接拿走它（粘进登录框就行）。**剪贴板里的口令跟着口令本身走**：还剩 12 秒就只留 12 秒，剩不到 5 秒时会明确告诉你「它马上就要换码」，免得你粘出一个已经失效的码还以为密码错了。**口令那一行是常显的**——复制用户名或密码不会把它藏起来，你随时能看到它跳到下一个。

### 四种取密钥的方式

按「码在哪里」选：

| 码在哪里 | 用什么 |
|---|---|
| 在另一台设备的屏幕上（手机、另一台电脑） | **扫码**：点「扫码」，把码放进取景框 |
| 已经存成图片文件 | **从图片**：选文件，自动识别 |
| 刚截好图，还在剪贴板里 | **粘贴截图**：在编辑器里直接按 `Ctrl+V`（**不需要先点任何按钮**），或点「粘贴截图」按钮 |
| 就在这块屏幕上、被 PasswordMS 自己挡着 | **截图**：点「截图」→ 程序自动隐藏 → 抓下整屏 → 程序带着这张**静止画面**回来 → 拖框圈住二维码 → 松开即识别 |

几点说明：

- 「粘贴截图」「截图」是**桌面端专属**——Android 读不到剪贴板里的位图，给了按钮也用不了，所以手机上只显示「扫码」与「从图片」。
- 截图是**多显示器整块**抓取，副屏上的码同样可以框。
- 框选是在**抓下来的静止画面**上做的：画面一旦抓定就不再变化，之后窗口显示与否都不影响你框到的内容，所以框的时候程序可以正常地待在前面。
- 框选层支持反向拖框（从右下往左上）、单击或拖出一条细线都不会报错，`Esc` 取消。**识别失败不会关闭框选层**，可以直接重框，不用重新截一次。
- 也可以直接把网站给的 `otpauth://` 链接粘进「TOTP 密钥」框，或手输 Base32 密钥。保存前会真正试算一次，密钥非法或参数不支持会当场拦下并说明原因，不会存进一个永远算不出正确口令的字符串。

### 支持的参数（有一条硬限制）

只支持 **6 位数字、30 秒周期、SHA1** —— 也就是绝大多数网站用的那一套。遇到 8 位验证码、60 秒周期、SHA256 之类的二维码或链接，程序会**明确拒绝并说清原因**（例如「这个网站用 8 位验证码，当前只支持 6 位」），而不是默默存下来让你以后对着一个永远被网站拒绝的口令发呆。

计数器式（HOTP，没有时间周期）同样会被明确拒绝。

### 安全

- 密钥与其它字段一样保存在加密保险库里，随库整体加密（导出备份、局域网同步都包含它）。
- 动态口令**在本机计算**；扫码解码也在本机完成（jsQR），二维码图片不会发到任何地方，也不联网。

## 🔄 同步怎么用（有一条硬限制）

**没有后台自动同步。** 同步只在你点「立即同步」时发生，这是刻意的取舍：手机息屏后 Android 会按应用丢弃它的全部网络包。这一条有实测对照——手机**醒着**时，往没人监听的端口发连接会立刻收到 `RST`（说明网络通、内核在正常拒绝）；手机**息屏休眠**后，扫描 16405 个端口全部零回应，连 `RST` 都没有（`ping` 却仍然通，因为 ICMP 不受按应用的网络限制）。要做到「随时可连」只能常驻一个前台服务（通知栏常挂 + 耗电），代价大于收益。

**任一端发起都行，但对端必须醒着：**

| 你在哪台设备上点「立即同步」 | 结果 |
|---|---|
| 电脑 → 手机 | 只有手机**亮屏、PasswordMS 在前台**时才可能成功；锁屏 / 休眠的手机收不到任何请求 |
| 手机 → 电脑 | 电脑通常一直醒着，所以这条**最可靠** |

所以「在电脑上点同步没反应」时，正确做法是**拿起手机、亮屏打开 PasswordMS、在同步页点「立即同步」**，把方向反过来。

其他前提与注意事项：

- 两端必须连**同一个 Wi‑Fi**（同一网段）
- 换网络或换 IP 后，配对记录里的旧地址会失效；点一次同步会自动做局域网发现并更新地址（只有同步成功后才写回）
- 若两端地址长期对不上、或发现始终无应答：**重新扫码配对**能立刻恢复
- 配对成功时两端会显示**同一个会话核对码**，请逐字核对——一致才算这次配对没被中间人隔开
- **Android 端必须授予「附近的设备」权限**：Android 17（API 37）起，应用访问局域网需要 `ACCESS_LOCAL_NETWORK` 运行时授权，未授予时本应用的连接会被系统**静默丢弃**（表现为「网络响应超时」，而同机的浏览器、输入法照常能连局域网）。v1.5.0 起应用会主动弹窗申请，**请点「允许」**；误点拒绝后可在 系统设置 → 应用管理 → PasswordMS → 权限 → 附近的设备 重新打开
- **实在连不上时的兜底**：电脑开一个**移动热点**、让手机连上它再配对/同步——热点里电脑就是手机的网关，这条路径不受上述局域网权限限制（2026-10-30 实测：手机在两台路由器 Wi‑Fi 下都超时，热点可用；真因已于 10-31 定位为该权限缺失，v1.5.0 修复）
- 同步页会显示本机 IP、当前监听端口，以及每台设备记录的地址——两端对照即可判断是「地址过期」还是「对端不在」

## 🔐 安全模型

- 保险库为**整卷加密**，密钥由主密码经 Argon2id 派生，绝不落盘
- 局域网同步采用端到端加密：配对后共享保险库密钥，传输数据对局域网内其他设备不可读
- 窗口闲置自动锁定；锁定状态下内存中的敏感数据被清零（zeroize）
- 剪贴板里的秘密按设定秒数自动清空（谁都能读剪贴板，这是唯一能减小的暴露窗口）；动态口令更短，只留到它自己失效为止
- 本软件**不联网上传任何数据**——所有数据仅存本机（及你主动配对的局域网设备）；唯一的例外是你手动开启「检查更新」后向 GitHub 查询版本号

## ⚠️ 免责声明 / 用户须知

1. **主密码无找回机制**：本软件不设后门、不提供密钥托管。忘记主密码意味着数据永久不可恢复，请妥善保管并定期使用「设置 → 导出」备份。
2. **卸载会带走保险库**：本软件不出于安全之外的任何理由备份你的库——Android 侧 `allowBackup` 是**刻意关闭**的（保险库不进第三方云）。因此删除应用、换机、重装系统都会删除本机库文件。**动手前请先「设置 → 导出保险库」保存一份加密副本**（锁屏页可用「从备份恢复」导入）。从系统设置卸载时 Android 会询问「是否保留应用数据」，勾选后重装同签名的 APK 可原样恢复；从应用商店或 `adb uninstall` 卸载不会弹这个框。
3. **导出后请亲眼看一眼文件大小**：设置页会常驻显示「上次成功导出：时间（体积）」，成功提示也会念出体积。**体积为 0 B 的备份等于没有备份**（1.5.2 之前 Android 端的导出正是这个故障，已修复）。导出的是一份加密副本，拿到它的人仍需主密码才能打开，但仍请妥善存放。
4. **软件按"现状"提供**：尽管开发中已尽力测试，仍不保证软件完全无缺陷。使用者应自行承担使用风险，并**定期备份重要数据**。
5. **不构成专业安全建议**：本软件不能替代完整的信息安全方案；请在可信设备上使用，并保持操作系统与 WebView2 运行时更新。
6. **局域网风险**：配对设备共享加密数据，请勿在不受信任的网络（公共 Wi-Fi 等）中进行配对操作。
7. **快速解锁的风险模型各不相同**：Windows Hello 的安全上限取决于本机 Windows 账户的锁屏强度（能拿到该账户登录凭据的人可以绕过它）；Android 侧则是「新增或删除指纹后，已保存的密钥永久失效」，需要重新开启。
