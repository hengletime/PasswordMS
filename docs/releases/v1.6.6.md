# PasswordMS 1.6.6

这一版只做两件事：把「删分组」的确认框改成说人话，把「同步页」缺了半年的那段说明补上。没有新功能，没有改加密，库文件格式一个字节都没动——旧版升级上来直接能开。

## 删分组时，按钮会告诉你按下去会发生什么

以前点分组行的删除图标，弹出来的框里写着「该分组下的条目将被移出分组或一并移入回收站，**请选择处理方式**」——可框里只有「取消」和「确定」两颗按钮，压根没有可选的处置方式。代码里固定走的是「移出分组」，也就是说：用户被要求选一个不存在的选项，然后按下一颗看不懂后果的按钮。分组里条目多的人按之前会犹豫——万一连条目一起删了呢？

现在这个框说的是实话：正文「该分组下的条目会被移出分组，不会被删除。」，主按钮直接叫**「移出分组」**。用户读完就知道条目不会丢，按下去也清楚自己按的是什么。

这一版**刻意没有**补第二个选项（「移入回收站」）。后端那条能力是现成的、也有用例，但把它接出来要把全局确认框从两态改成三态，动到十几处调用点，与「越简单越好」相悖。真需要连条目一起删，先删分组、再逐条删，路径是通的。

## 同步页补上了「为什么连不上」那段说明

同步卡片的底部一直缺一段话，而这段话是当初设计时就写好、并且明确要求常驻的：**同步前要让另一台设备解锁并保持 PasswordMS 停在前台**（手机一息屏，系统就掐断它的网络，本机既连不上、也收不到任何应答）；**两端「本机网络」里的地址应该属于同一网段**；**如果对端地址长期对不上，请重新扫码配对**。

它没写进代码，是因为上一版改同步页时只落了「本机网络」和「记录地址」两行，这段被漏掉了。现在它常驻在卡片底部，不进任何折叠——能解释失败的话，就该一直看得见。

顺带清掉了一批从来没人用过的界面文案（619 条，比上一版少 32 条），这些字一个都没在屏幕上出现过，删掉不影响任何界面，只是让翻译表不再骗人。

## 已知限制

- **这一版还没有人真机走过**。上面的改动在自动化门禁里是全绿的（11 门、0 跳过），但「删分组的新文案与新按钮」「同步页底部那段话在手机窄屏上的排版」这两处，只有在真机上看过才算数。接下来会按走查单 3.81 / 3.84 / 3.88 逐条走。
- 删分组仍然只有「移出分组」一个处理方式（见上，本次刻意不加第二个选项）。
- 生物识别那类「去系统设置录完指纹、切回 App，卡片当场变」的承诺，文案里依然**没有**写「会自动重新检测」——功能已经修好，但按规矩要真机验过（走查单 5.10）才允许写进文案。

## English summary

1.6.6 has no new features and no changes to encryption or the vault format; existing vaults open as-is.

**Deleting a folder now tells the truth.** The confirmation dialog used to say "choose how to handle the items" while offering only Cancel/OK and always moving items out of the folder. The body now reads "Items in this folder will be moved out of it. Nothing is deleted." and the primary button is labelled **Move out**. We deliberately did not add a second option (move items to trash): the backend supports it, but wiring it up would turn the global confirm dialog from two-state into three-state across a dozen call sites.

**The sync page gained the explanation it was missing.** A standing hint now sits at the bottom of the status card: unlock the other device and keep PasswordMS in the foreground before syncing (a phone that sleeps loses its network silently), both sides' addresses should be on the same subnet, and if the peer address never matches, re-scan the pairing QR code.

Also removed 32 dictionary entries that no screen ever rendered (619 keys now); no visible change.

**Known limitation:** these changes have not yet been verified on real devices. The automated gate is fully green (11 gates, 0 skipped), but the new folder-deletion wording and the layout of the sync hint on a narrow phone screen still need a hands-on pass.
