# PasswordMS 1.6.9

这一版只改了一件事：设置页不再把内容挤在左边、右边空一大片——窗口拉宽后，设置卡片分成左右两列排布，每张卡片标题还带了一个小图标，找设置项更快。

## 设置页右边那一大片空白，现在用起来了

 windows 窗口拉宽以后，以前所有设置项仍然挤在左边 680 像素以内，右边空着一大片，看着别扭。根因很直接：设置区的宽度被人写死了一个上限，窗口再宽它也不往外扩。这一版把这个上限去掉，让设置区跟着窗口一起变宽，并把卡片排成左右两列。

## 为什么是两列"各自堆放"，不是简单的网格

第一版做成两列网格，结果更难看：同一行里「外观」卡只有两行、「系统集成」卡却很长，矮卡底下就空出一大块，上下参差。参考页面好看的关键不是"两列"本身，而是**两列各自独立往上堆**——列内卡片紧紧相连，列与列之间根本不要求底部对齐。

所以最终改成了两个独立的列：左列放外观、系统集成、安全、快速解锁、密码体检、改密码；右列放导入、导出保险库、恢复点、设备、库文件、关于。每列内部卡片紧密相连，再没有行末的锯齿留白。

## 导入和导出放在一起了

按真机反馈，把「导入」挪到了右列、紧挨着「导出保险库」上方——这两件事本来就是一对，放在一起既顺手，也顺便把左右两列的高度拉得更齐。两列现在各 6 张卡。

## 每张卡片标题有了小图标

12 张设置卡片各配了一个语义图标：外观是太阳、安全是盾牌、快速解锁是钥匙、导入导出是上下箭头、恢复点是时钟、改密码是锁、库文件是文件、关于是地球。全部复用程序里已有的图标，没有新增任何依赖，也没有新增一句需要翻译的文案。

手机上仍然是一列，卡片顺序和桌面一致，原来的窄屏适配一字未动。

## 已知限制

- 手机端（窄屏）仍是单列，不提供两列布局——小屏放两列会把每行挤得读不清。
- 左侧竖排导航没有照搬参考页面：本程序桌面导航在顶栏、手机在底栏，是全程序统一的布局，为设置页单独改一套会与其它页面不一致。
- 主题选择仍沿用原来的「跟随系统 / 浅色 / 深色」三按钮，没有加参考页面那种色块预览——那只是装饰，语义并无增加。
- 本版只动排版，不涉及任何功能、加密或同步逻辑；保险库数据格式与 1.6.8 完全相同。

## English summary

This release is purely a visual refresh of the settings page. On wide windows, settings used to be squeezed into a fixed 680-pixel column on the left, leaving a large empty area on the right. That width cap is gone, and the settings cards now flow in two columns that fill the available space.

The two columns are stacked independently rather than aligned in grid rows. An early grid attempt looked worse: a short card next to a tall one left an ugly gap underneath. The final layout matches the reference design — cards are tightly packed within each column, and the columns are not forced to line up at the bottom.

Import was moved next to Export in the right column, since they are a natural pair; the two columns now hold six cards each. Every card title also gained a small semantic icon (sun for appearance, shield for security, key for biometric unlock, arrows for import/export, clock for restore points, lock for password change, and so on), reusing icons already in the app — no new dependencies and no new translatable text.

On phones the layout stays single-column with the same card order; the existing narrow-screen rules were untouched. Known limits: no two-column layout on small screens, no left-side navigation (the app uses a top bar on desktop and a bottom bar on mobile), no theme colour-swatch preview, and no changes to functionality, encryption, or sync — the vault format is identical to 1.6.8.
