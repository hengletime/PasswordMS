## 1. 一句话定位

一款**体积小巧、本地优先、零知识**的密码管理工具，同一套代码同时运行在 Windows 桌面与 Android 手机，通过局域网二维码配对完成设备间加密同步。

参考对标：Bitwarden（借鉴其核心能力与数据模型，但**不做**其云端账号体系与浏览器扩展）。

---

## 2. 已冻结的四项决策（不可擅改）

| 编号 | 决策点 | 结论 | 影响 |
|------|--------|------|------|
| D1 | 技术栈 | **A · Tauri 2**（Rust 核心 + Svelte UI，单套代码双端编译） | 决定仓库结构、加密库选型（RustCrypto）、体积基线 |
| D2 | 局域网同步 | **① 二维码配对直连**（Windows 监听端口，手机扫码带入 IP + 端口 + 一次性令牌，配对后共享同步密钥，载荷端到端加密） | 决定同步协议、配对流程、UI 交互 |
| D3 | MVP 范围 | **② P0 + P1**（核心功能 + TOTP + 密钥文档 + Bitwarden 导入 + 回收站 + 密码体检） | 决定本期交付边界，P2 进 backlog |
| D4 | 「密钥文档」定义 | **c · 两者都要**：既支持**加密附件文件**（二进制 blob），也支持**文本型安全笔记** | 决定数据模型需同时具备 `attachment` 与 `secure_note` 两种条目类型 |

## 3. 体积硬约束（一号约束）

| 交付物 | 上限 | 说明 |
|--------|------|------|
| Windows 安装包 | **≤ 10 MB** | 复用系统 WebView2，不打包浏览器内核 |
| Android APK | **≤ 12 MB** | Rust 静态库按需裁剪，无冗余依赖 |

**因此禁止**：Electron；整包引入 Ant Design / MUI 等重型 UI 框架；图标字体包（改用内联 SVG）；任何未列入白名单的沉重依赖。

## 4. 功能池

### P0 · 核心最小集（必须交付）

| ID | 功能 | 说明 |
|----|------|------|
| F-01 | 主密码解锁 / 创建保险库 | 首次使用创建保险库并设定主密码 |
| F-02 | 自动锁定 | 1 / 5 / 15 分钟可配，失焦或超时锁定 |
| F-03 | 分组管理 | 新增、重命名、编辑、删除、排序；分组含名称、图标、颜色 |
| F-04 | 条目管理 | 字段：标题、网址、用户名、密码、备注、自定义键值对；增删改查 |
| F-05 | 一键直达 | 点击条目网址直接调用系统默认浏览器打开 |
| F-06 | 一键复制 | 分别复制用户名 / 密码，剪贴板 30 秒后自动清空 |
| F-07 | 密码生成器 | 可配长度、大小写、数字、符号、排除易混字符 |
| F-08 | 搜索与收藏 | 全库模糊搜索；条目可标记收藏并置顶 |
| F-09 | 局域网配对与同步 | 二维码配对 + 手动触发同步 + 同步状态提示 |
| F-10 | 加密存储 | 单文件加密保险库，Argon2id + 逐条 AEAD 加密 |

### P1 · 本期必须一并交付（因 D3 决策）

| ID | 功能 | 说明 |
|----|------|------|
| F-11 | TOTP 内置验证器 | 支持扫码 / 手动录入密钥，条目详情页展示动态验证码与倒计时 |
| F-12 | 密钥文档 · 加密附件 | 上传任意文件（SSH 私钥、许可证、证书等），以密文 blob 存入保险库，可导出 |
| F-13 | 密钥文档 · 安全笔记 | 纯文本型加密条目，用于恢复码、API Key、备注等长文本 |
| F-14 | Bitwarden 导入 | 支持导入 Bitwarden 导出的 JSON 与 CSV，含字段映射预览 |
| F-15 | 回收站 | 删除条目进回收站，保留 30 天，支持还原与彻底删除 |
| F-16 | 密码健康体检 | 统计弱口令、重复使用、超期未改，给出整改建议 |

### P2 · 二期 backlog（本期不做，仅登记）

- 生物识别解锁（Windows Hello / Android 指纹）
- Android 系统级自动填充（Autofill Framework）
- Windows 全局热键快速搜索 + 自动输入
- 标签 / 多视图（按类型、最近使用）
- 密文快照版本历史

### ❌ 明确不做（本期与可预见未来都不做）

| 项 | 理由 |
|----|------|
| 浏览器扩展 | 体积与工程量爆炸，且需维护多浏览器 |
| 云端账号服务 / 任何服务器 | 零知识本地优先，无服务器即无被拖库风险 |
| 团队共享 / 组织架构 / 权限 | 个人工具定位，企业能力不在范围 |
| Web 端 | 浏览器内运行会破坏「本地保险库」安全模型 |
| 遥测 / 崩溃上报 / 广告 | 隐私底线 |

## 5. 安全底线（不可妥协，PRD 与架构均须落实）

1. **零自研密码学** —— 只用经过审计的成熟库，算法与参数写入文档留档。
2. **零知识同步** —— 局域网同步只传密文载荷，对端永不接触明文。
3. **主密码不落盘** —— 不以任何形式持久化主密码或其派生前的明文。
4. **逐条加密** —— 修改单条不需重写全库；单条密钥由保险库主密钥包裹。
5. **内存与痕迹** —— 剪贴板定时清空；锁定后清空敏感内存；日志不记录任何凭据。
6. **统一化报错** —— 解密失败等错误提示不得区分「密码错」与「数据损坏」，避免侧信道。
