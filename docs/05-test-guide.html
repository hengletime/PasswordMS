2 · 第 2 关：Android 真机

2.1 安装

APK 在这儿（在仓库外面，是测试签名版）：

D:\AndroidDev\out\PasswordMS-0.1.0-arm64-test.apk    （6.35 MB）

方式 A · 用 adb 装（推荐） —— 手机要打开「开发者选项 → USB 调试」，插上数据线：

"D:\AndroidDev\sdk\platform-tools\adb.exe" devices -l
"D:\AndroidDev\sdk\platform-tools\adb.exe" install -r "D:\AndroidDev\out\PasswordMS-0.1.0-arm64-test.apk"

方式 B · 手动装 —— 把 apk 拷到手机（数据线/微信传文件都行），在手机上点开安装，系统会问"允许安装未知来源应用"，允许即可。

装不上时先看这两条 ① 手机安卓版本必须 7.0 或更高（这个包 minSdk=24）。
② 如果之前装过别的签名的同款，要先卸载旧版才能装（签名不一致，安卓会拒绝覆盖）。

4 · 已知边界（这些不是 bug，先别急着报）

现象说明
扫码功能用不了扫二维码需要真机摄像头 + 授权。没有摄像头请走"粘贴配对文本"，功能等价。
Android 6 及以下装不上本包 minSdk=24（Android 7.0）。低版本系统安卓会直接拒绝安装。
用测试证书签名证书在 D:\AndroidDev\keystores\passwordms-test.jks，口令是明文弱口令，仅供测试。正式发布要另建正式证书，否则以后无法升级（签名不一致）。
sync_accept_pair 好像什么都没做它目前是个空实现，且界面并没有调用它。你在日志里看到它没动作，属正常。
没有 UI 自动化测试目前只有 37 个 Rust 单元/集成测试，界面部分只能靠你手动点。这也是这份指南存在的原因。
没有 cargo fmt --check 结果本机没装 rustfmt 组件，格式化检查暂缺。
首次解锁要等 2 秒左右主密码派生（Argon2id）故意做得慢，这是安全特性，不是卡顿。整数范围约 1.8–2.1 秒。
