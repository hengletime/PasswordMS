## PasswordMS 项目启动（需求讨论轮 · 未开工）

**主人需求**：跨端密码管理工具，Windows 可用 + 安卓可用，支持局域网同步，程序体积要小，参考 Bitwarden。
功能：① 分组 CRUD；② 保存网址 + 用户名 + 密码，一键直达；③ 保存密钥文档。

**小李（software-company 专家团主理人）给出的方案要点**：
- 技术栈推荐 **Tauri 2 + Svelte + Rust core**（一套代码覆盖双端，Win 安装包 3–8MB / APK 5–10MB）；备选 Flutter（15–25MB）与双端原生。
- 安全底座：Argon2id 派生主密钥 → 包裹 DEK → 条目级 XChaCha20-Poly1305；零知识；自动锁定；剪贴板 30s 清空；Android FLAG_SECURE；密钥存系统 Keychain/Keystore。
- 局域网同步：**二维码配对（IP+端口+一次性令牌）+ 局域网 HTTP + 载荷端到端加密**；条目级 last-write-wins 合并。mDNS 自动发现为备选，手动加密文件导入导出作兜底。
- 功能池 P0（分组/条目/生成器/搜索/自动锁定）→ P1（TOTP、密钥文档附件、Bitwarden JSON 导入、回收站、密码体检）→ P2（生物识别、安卓自动填充、全局热键）。
- 明确不做：浏览器扩展、云端账号、团队共享、Web 端。
- 体积预算：Win ≤10MB、APK ≤12MB；拒绝 Electron 与整包 UI 框架。

**状态**：等主人在 4 个决策点（技术栈 / 同步方案 / MVP 范围 / "密钥文档"定义）确认后，再由主理人 TeamCreate 并启动 SOP 工作流。

## PasswordMS 真实编译验证（晚 · 关键转折）

**结论：`03-impl.md` §5 的 `IS_PASS: YES` 是误判，已撤回改判 NO。** 该结论是**无编译器环境下的静态文本审查**（grep+人工比对），只能证明「引用与声明对齐」，**不能证明类型正确**。

**真实编译器暴露 16 个错误**（新增权威文档 `docs/03b-verification.md`）：
- 生产代码 11 处：10× `E0308`（`&Zeroizing<[u8;32]>` 传给已放宽的 `&[u8]` 形参，漏了 `[..]` 切片——session.rs 82/83/125/126/177/178/189/190、repository.rs 945/946）+ 1× `E0603`（container.rs:25 `FRAME_HEADER_LEN` 私有转导入）
- 测试代码 5 处：4× `E0308`（crypto_vectors.rs 57/58/68/69）+ 1× `E0425`（container_roundtrip.rs:59 调了不存在的 `keys::derive_kek`，应为 `kdf::derive_kek`）
- **根因归纳**：AEAD/KDF 密钥参数从 `&[u8;32]` 放宽到 `&[u8]` 时，`Zeroizing<[u8;32]>` 的 `Deref` 只解一层（到 `[u8;32]`），调用点必须显式 `&x[..]`。
- 测试错误此前不可见：`cargo test` 在链接阶段就死了，测试源码未被完整类型检查。

### MSI 打包：WiX 缓存手工预热法（可复用）

`tauri build` 的 NSIS 步骤完全成功，但 MSI 步骤卡在从 GitHub 下载 `wix314-binaries.zip`（实测 ~17KB/s，16 分钟未完成）。

**解法：绕过 GitHub 直连，手工预热 Tauri 的 WiX 缓存。**
1. 用 GitHub 加速代理下载（`ghfast.top` 实测可用，41.3 MB 全量拿到；`gh-proxy.com`/`ghproxy.net` 备选）：
   `curl -sL -o wix314-binaries.zip "https://ghfast.top/https://github.com/wixtoolset/wix3/releases/download/wix3141rtm/wix314-binaries.zip"`
2. 解压（Windows 自带 `C:\Windows\System32\tar.exe` 即 bsdtar，支持 zip）到 **`%LOCALAPPDATA%\tauri\WixTools314\`**（220 个文件，含 `candle.exe`/`light.exe`/`wix.dll`/`sdk/`/`x86/`/`doc/`）。
   → 目录名 `WixTools314` 是从 `node_modules/@tauri-apps/cli-win32-x64-msvc/cli.win32-x64-msvc.node` 里 grep 出来的（`grep -aoE "WixTools[0-9A-Za-z]*"`）；本机**没有 `strings` 命令**，得用 `grep -a`。
3. 重跑 `npx tauri build --bundles msi`，Tauri 检测到缓存目录已存在即跳过下载。

> 通用套路：Tauri 所有外部工具（NSIS/WiX）都缓存在 `%LOCALAPPDATA%\tauri\`，且**只要目标目录存在就跳过下载**——国内弱网环境下优先用这招，别硬等 GitHub。
